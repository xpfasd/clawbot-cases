# 技能模板索引

> 本目录包含所有技能配置模板

## 📂 目录结构

```
skills/
├── README.md              # 本索引文件
├── weather.json           # 天气技能模板
├── github.json            # GitHub 技能模板
├── coding-agent.json      # 编程助手模板
└── custom-skill-template.md # 自定义技能模板
```

## 🎯 模板列表

| 技能 | 描述 | 难度 |
|------|------|------|
| Weather | 天气查询 | ⭐ |
| GitHub | GitHub 操作 | ⭐⭐ |
| Coding Agent | AI 编程 | ⭐⭐⭐ |

## 💡 使用方法

1. 下载模板文件
2. 根据需求修改配置
3. 放入 `~/.openclaw/skills/` 目录
4. 重启 Gateway
